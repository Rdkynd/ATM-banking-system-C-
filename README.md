# ATM-banking-system-C
A simple consele-based ATM banking system written in C
##Description
This project is simple ATM simulation developed using the C programming language.
It allows users to perform basic banking operations through a menu-driven console interface
##Features
-Balance inqury
-Deposit Money
-Withdraw Money
-Input validation
-Continous menu until exit 
##Concepts Used
-Variables and data types
-Loops(while,do-while)
-Switch-case
-Macros(#define)
-Basic input/output

##Program Flow
The program displays a menu repeatedly until the user chooses to exit.
Each menu option performs a specific banking operation with proper input validation.

##Limitations
No PIN authentication
No transaction history
Data is not saved after program termination
